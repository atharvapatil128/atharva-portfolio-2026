# content/brain

Hand-written background that the /ask assistant can draw on, and that does not
belong in a case study.

**This directory is published.** Every word here is sent to the model and can be
repeated to any visitor who asks the right question. It is a curated export, not
a vault sync. Do not point it at an Obsidian vault or copy notes in wholesale:
half-formed opinions, notes about named people, compensation thoughts, and
anything said in confidence do not belong here.

The test before adding a file: would you be comfortable if a recruiter read this
sentence aloud back to you in an interview? If not, it does not go in.

Files are plain Markdown. Filenames are ignored, only the contents are used.
Run `npm run corpus` after editing so the change reaches the assistant.
